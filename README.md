# StockTradingSystem
##Description:
This Java-based application enables users to manage and trade stocks. Users can buy, sell, and view stock transactions and prices.

## Features:
- View available stocks.
- Buy and sell stocks.
- Track user portfolio.

## Technologies Used:
- Java

## How to Use:
1. Clone this repository:
   ```bash
   git clone https://github.com/rizwana07/StockTradingPlatform.git

2. Open the project in your preferred IDE (e.g., Eclipse, IntelliJ).


3. Locate and open the Main.java file.


4. Run the Main.java file to start the application.
